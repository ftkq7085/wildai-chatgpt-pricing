### 第三步：登录自己的 ChatGPT 账号

按页面提示跳转到 ChatGPT，登录需要开通 Plus 的账号。完成登录后返回 WildAI，再点击继续。

- 获取会话信息时，浏览器其实没有登录；

如果页面显示空白对象或空内容，通常说明登录状态不正确，应先回到 ChatGPT 确认登录，再重新获取。
